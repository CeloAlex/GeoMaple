# GeoMaple (SGCIM) — Primeiro acesso

**Endereço do sistema:** https://geomaple.up.railway.app

## Passo 1 — Criar uma conta para o novo usuário (feito pelo administrador)

Não compartilhe o login `admin` com o tester — o sistema tem trilha de auditoria por
usuário, e cada pessoa deve ter sua própria conta.

1. Faça login em https://geomaple.up.railway.app com sua conta de administrador.
2. No menu superior, abra **SGCIM → Gerenciar usuários**.
3. Clique em **+ Novo Operador**.
4. Preencha:
   - **Nome**: nome do tester
   - **E-mail institucional**: e-mail do tester
   - **Login**: pode deixar em branco (é gerado automaticamente a partir do nome)
   - **Perfil**: `Editor` é o recomendado para testar cadastro/edição de imóveis;
     use `Administrador` apenas se o tester também precisar testar a gestão de usuários
   - Matrícula/Setor/Telefone são opcionais
5. Clique em **💾 Criar operador**.
6. A senha temporária aparece **uma única vez**, em um modal, na tela. Copie-a
   imediatamente — ela não pode ser recuperada depois (só resetada de novo, gerando
   uma nova senha, pelo botão 🔑 na lista de operadores).
7. Envie ao tester, por um canal separado do login (ex.: WhatsApp/e-mail): o endereço do
   sistema, o login gerado e essa senha temporária.

## Passo 2 — Primeiro acesso do tester

1. Acesse **https://geomaple.up.railway.app**
2. Entre com o **login** e a **senha temporária** informados.
3. O sistema vai pedir imediatamente para definir uma senha definitiva (tela
   "Troca de senha obrigatória") — a senha temporária não pode ser reutilizada como senha
   final.
4. Depois de definir a senha, o acesso ao sistema é liberado normalmente.

## Se a senha temporária for perdida

O administrador pode gerar uma nova a qualquer momento em
**SGCIM → Gerenciar usuários**, clicando no botão 🔑 (resetar senha) ao lado do nome do
operador — isso invalida a senha anterior e gera uma nova, exibida uma única vez.
